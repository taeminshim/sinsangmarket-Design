## Claude 데스크톱 앱에서 쓰기 (스킬)

이 저장소는 Claude 스킬 `sinsangmarket-design`으로도 쓸 수 있어요. 스킬이 켜져 있으면 신상마켓 화면 작업을 할 때 Claude가 이 기준을 알아서 따라요.

- **설치**: 조직 관리자가 [`dist/sinsangmarket-design.skill`](dist/sinsangmarket-design.skill)을 받아 조직 스킬로 한 번 올리면 팀원 모두에게 켜져요. 관리자 배포가 어려우면 각자 데스크톱 앱에서 이 파일을 스킬로 추가해도 돼요.
- **키 표는 항상 최신**: 스킬이 작업할 때마다 이 저장소의 `keys-mobile.md`·`keys-pc.md` 최신본을 읽어요. 키를 추가해도 스킬을 다시 배포할 필요가 없어요.
- **키 추가**: 다 그린 뒤 Claude가 "키 표에 추가할까요?"라고 물어요. 그렇다고 하면 붙여넣을 줄과 GitHub 편집 링크를 줘요. 링크를 열어 붙여넣고 **Commit changes**만 누르면 돼요 (협업자 권한 필요, git 설치 불필요).
- **스킬 다시 만들기**: 키 표 말고 규칙·가이드 문서(`skill/sinsangmarket-design/SKILL.md`, `libraries.md`, `design-system/`, `builder/`)를 고쳤을 때만 `python3 scripts/build_skill.py`로 `dist/`의 스킬 파일을 다시 만들어 커밋하고, 관리자에게 다시 올려달라고 해요.

## 그리기 전 규칙

1. **원본 찾기는 먼저 물어봐요.** 원본을 찾는 데 시간과 토큰이 많이 들어요. "만들어줘"라는 요청을 받으면 바로 찾지 말고 "as-is 원본을 찾아서 할까요?"라고 먼저 물어요. 찾으라고 할 때만 아래 [as-is 원본 화면 찾기](#as-is-원본-화면-찾기)로 가요.
2. **디자인 시스템 먼저, 빌더는 그다음이에요.** 디자인 시스템에 있는 컴포넌트를 먼저 써요. 디자인 시스템에 없을 때만(예: 상품 썸네일·카드) UI Builder에서 가져와요.

## 자주 쓰는 키 추가하기

팀원 누구나 키 표를 채울 수 있어요. 화면을 다 그린 뒤 Claude가 이렇게 해요.

1. **먼저 물어요.** 이번 작업에서 키 표([keys-mobile](design-system/keys-mobile.md) · [keys-pc](design-system/keys-pc.md))에 없는 컴포넌트·스타일을 썼고, 다른 화면에서도 자주 쓸 것 같으면 목록을 보여주고 "키 표에 추가할까요?"라고 물어요. 묻지 않고 커밋하지 않아요.
2. **확인하고 넣어요.** 추가하겠다고 하면 키를 실제로 한 번 불러와서 되는지 확인해요. 모바일은 keys-mobile, PC는 keys-pc의 맞는 표에 넣어요 (누가 언제 넣었는지는 커밋 기록에 남아요). 이미 있는 이름이면 새로 줄을 만들지 않고 그 줄을 고쳐요.
3. **쓸 때 주의도 같이 넣어요.** 그 컴포넌트를 쓰다가 막혔던 점이 있으면 같은 파일의 "쓸 때 주의" 표에 한 줄로 적어요.
4. **커밋해요.** 최신 내용을 먼저 받고(`git pull`), 키 파일만 커밋해요. 메시지는 `키 추가(MO|PC): 컴포넌트 이름` 형식이에요.

## as-is 원본 화면 찾기

원본을 찾으라고 했을 때 여기서 찾아요.

- [최신화 파일위치 (Figma 인덱스)](https://www.figma.com/design/8ayuu3IXhH84DfVrCJaEcO) — 서비스 영역별 최신 원본 파일 링크
- [최신화 산출물 (엑셀)](https://docs.google.com/spreadsheets/d/1GdfSsQ8HYBZTCBX8lQg0CA6ohf8sEwzHrYHYFmkiE_g) — 같은 목록을 시트로 관리

찾은 뒤에는
- 원본 프레임을 복제해 **원본과 수정안을 나란히** 둬요.
- 원본 링크는 [공통 가이드](https://www.figma.com/design/kALfVcz3XXSG2p91vFJ7oZ?node-id=1-173)의 타이틀에 넣어요.
  - 원본 화면 위에 `2depth` 헤더를 놓고 `position = AS-IS`로 바꿔요 → `[AS-IS] 타이틀`
  - 타이틀은 `Text 2` 속성이에요 (`Text`가 아니에요). 원본 화면 이름을 적어요.
  - 화면 이름마다 원본 프레임 링크를 걸고 **밑줄 + 노란색(#FBFF27)** 으로 표시해요. 공통 가이드의 기획서 링크와 같은 스타일이에요.
  - 예: `[AS-IS]` <u>배송지 추가_일본</u> · <u>배송지 수정_일본</u>
  - 수정안 위의 헤더는 영역에 맞는 `position`(로컬[소매]·로컬[도매]·글로벌[소매]·공통)을 써요.
- 원본 안의 일부 컴포넌트는 다른 파일로 불러와지지 않아요. 그럴 땐 디자인 시스템 컴포넌트로 다시 조립해요.
